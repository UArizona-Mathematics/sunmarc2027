# SUnMaRC 2027

Website for the Southwestern Undergraduate Mathematics Research Conference, April 2–4, 2027, at the University of Arizona in Tucson.

Expected website: https://uarizona-mathematics.github.io/sunmarc2027/

## Publishing

In Settings → Pages, choose **Deploy from a branch**, **master**, and **/ (root)**, then Save. GitHub Pages builds the Jekyll source in the repository root; do not publish the historical `_site` directory. Check the Actions tab for the deployment result.

## Editing

Edit the root Markdown pages and commit to master. Navigation is in `_includes/sidebar.html`; site settings are in `_config.yml`.

Read [CONTENT-NOTES.md](CONTENT-NOTES.md) for verified sources and outstanding organizer inputs. Replace pending notices only with confirmed information. Historical PDFs, portraits, and old generated output remain in Git but are excluded from the published site.

The original Hyde theme license is retained in LICENSE.md.
